# Taktiktavla

Kompakt vertikal webapp för en fotbollstaktiktavla med avbytaryta.

## Funktioner

1. Bredare vertikal whiteboard-plan.
2. Avbytaryta till vänster.
3. Röda magneter.
4. Blå magneter.
5. Gula målvaktsmagneter.
6. Röda avbytarmagneter med gul väst.
7. Blå avbytarmagneter med gul väst.
8. Valfri siffra eller text i magneten.
9. Tom siffra eller text ger initialer automatiskt.
10. Namn visas under varje magnet.
11. Magneter kan dras fritt över plan och avbytaryta.
12. Dubbelklick på magnet ändrar namn och siffra eller text.
13. × tar bort magnet.
14. Tavlan sparas i localStorage.

## Starta

Öppna `index.html` direkt i webbläsaren.

Alternativt starta en lokal server:

```bash
python3 -m http.server 8000
```

Öppna sedan:

```text
http://localhost:8000
```
