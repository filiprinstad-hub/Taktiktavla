# Taktiktavla

iPhone-fixad version av taktiktavlan.

## Ändringar

1. Mobilvyn använder hela tillgängliga skärmhöjden bättre.
2. Tavlan blir större på iPhone.
3. Avbytarytan ligger kvar till vänster.
4. Menyn är kompakt och tar mindre höjd.
5. Dynamiska iPhone-vyhöjder hanteras med `svh`.
6. Magneterna går att dra på både plan och avbytaryta.

## Starta

Öppna `index.html` direkt i webbläsaren.
